# qa-auditor 质检员（离线后台 Agent）

不是聊天入口：客人在会话里指定本 Agent 会被接入侧拒绝。所有能力由后台任务 `qa.audit`
驱动，或经管理端「数据质量」页的同步触发（`GET /admin/quality/audit`）。

## 职责

扫描增量会话与知识库，产出可复核的质检信号，不阻断业务：

| 产出 | 判定 | 落点 |
| --- | --- | --- |
| `unresolved` 标注 | 窗口内有点踩（downvote）的线程 | `qa_labels`（`source='auto'`） |
| `handoff_requested` 标注 | 窗口内有转人工请求的线程 | `qa_labels` |
| `complaint_risk` 标注 | 客人消息命中投诉关键词（投诉/退款/赔偿…） | `qa_labels` |
| 过期文档 | `indexed` 且超过过期阈值未更新 | 跑批任务结果（元数据） |
| 低召回知识库 | 最新评估报告 `recall_at_k` 低于阈值 | 跑批任务结果 |
| 覆盖缺口 | 点踩消息里尚未覆盖的问题 | 跑批任务结果（FAQ 草稿建议） |

标注幂等：同线程同标签已存在即跳过。跑批失败不自动重放，下一次调度补齐即可。

## 配置

| 键 | 含义 | 默认 |
| --- | --- | --- |
| `scan_window_hours` | 会话扫描窗口 | 24 |
| `stale_days` | 文档过期阈值（天） | 180 |
| `low_recall_threshold` | 低召回判定阈值 | 0.7 |

配置在管理端「Agent 配置」里按 slug `qa-auditor` 保存；`qa.audit` 任务执行时读取，未配置
则用上表默认值。

## 触发

- **定时**：task worker 每小时提交一次（小时级去重键，同一小时至多一次，重启补发不堆积）。
- **手动**：管理端数据质量页的同步触发（不建任务，直接跑一轮并返回结果）。
